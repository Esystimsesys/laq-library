## 繰り返した指摘と原因の振り返り

「不足していた確認」は、コメントと修正経過からの作業上の判断であり、自動計測した原因ではない。

| 観測した指摘・修正 | 不足していた確認 | 次の作品での対策 |
|---|---|---|
| 後頭部・襟の黄色い板、最後には頭と首の右側の白い三角も表裏を反転 | 全体の輪郭が合っても、板ごとの表面や鏡映した側の向きを確認しきれていなかった | 左右を個別に裏と斜めから照合。表裏とNo.5の折れ方向を別項目として確認する |
| No.5/6/7の取り違え、余る口の上下や腕の外向きなどを修正 | 接続する角度・口数・残る口の向きの組を確かめる必要があった | 番号だけの置換で終えず、使用口・空き口・接続先の板の姿勢まで一緒に見直す |
| 頭の後方、首の三角、胴の側面・下面、腕先と尾の装飾を追加。不必要な面とジョイントを削除 | 見えている輪郭や連結性を優先し、隠れる面・末端・空き口の先を追い切れていなかった | 塊ごとの板の数・種類・色順を写真に対応付け、空き口の先も確認。不明箇所は推測として残す |
| 胴のNo.1をNo.2へ変更し、三角の色順や向きを修正 | 側面を大まかな面で置くと、細かな板割りと写真の並びが一致しなかった | 正方形・正三角形を単位に根元から並びを記録し、複数方向で比較する |
| 頭と胴で、先に付けたジョイントが次の板の差し込みを妨げると指摘 | 完成時に連結することと、途中で差し込めることを分けて扱えていなかった | 原則として新しい板にジョイントを先付けし、その板を付ける手順へ移す。複数辺で閉じる直前の挿入方向を確認する |
| 「左も同様」「逆側も同様」が繰り返された | 対の部位を一緒に照合する必要があった | 対称と確定している部位は片側の修正時に両側を点検。ただし見えない側まで観測済みにはしない |
| 内部の英語IDが表示され、最後に手順名と矢印サイズも統一 | 制作画面と利用画面の表示ルールの確認が不足した | 共通描画と共通ラベルを初めから使い、取り込み時に双方の表示を確認する |

## 今回維持できた進め方

- 「頭はOK」「手順4までOK」の範囲を保持し、後続の指摘の対象へ修正を限定した。
  必要な合体位置の変更では塊の内部形状を保ち、推定の配置をreplyへ記録した。
- 最新の保存ガイドとの差分を使い、からだ①の手動移動・色変更、別作業で校正したNo.5を生成器の値へ戻さなかった。
  最後の表裏4件は法線だけを変更し、座標・接続・手順を保持した。
- コメントへ対応内容を返信し、人が確認する流れを維持した。対象の選び直しがあったコメントは会話や後続の選択と照合した。
- レビューが続く間は構造検証と変更箇所の確認へ絞った。全手順・全画面幅の試験を各コメントで繰り返さず、
  最終同期で必要なビルドと表示テストをまとめた。

これらは次回も維持する。特に生成器は完成ガイドの完全な原本ではなく、人の保存済み編集と比較・統合するための補助として扱う。

## 次回に残す判断と限界

対策の実施場所は [AI-3D-WORKFLOW.md](AI-3D-WORKFLOW.md) の「初回提示前に確認すること」と
「コメントを順次取り込むとき」。新規作業の`AI-PROMPT.md`は既にこのワークフローを読むため、別の重複したスキルは作らない。
少数の代表部品だけでなく、最初に各方向と全手順を一巡して同種の問題をまとめて拾い、その後は変更範囲に絞る。
指摘件数をゼロにする保証ではなく、今回のような同種の取りこぼしを初回提示前に減らすためのルールである。

ユーザーの完成確認は画面上のガイドの受け入れであり、すべての接続の幾何・実物確認とは別。

生成モデルの過去の検査合格を現在のガイドへ転記しない。今後それらを直す場合も既存の手動配置を黙って置き換えない。
