# ミニシャフト・ミニホイール（制作室）

制作室でミニシャフトとミニホイールを追加・再接続・削除し、ガイドとともに保存できる。
公式の形状画像から作った表示モデルで、実測CADではない。オオスズメバチから公開作品でも表示できる。

## 使い方とレビュー

No.1/No.2を選び、「選択したパーツにつなぐ」で空き辺と「ミニシャフト」を選んで追加する。
ミニシャフトには板用の差し込み口が3つ（No.7のようなT字）と「ホイール用の軸」が1つある。
軸を選ぶとミニホイールを追加できる。空き軸穴のミニホイールからシャフトを追加することもできる。
ミニシャフトは黒、ホイールは黒タイヤ・白リムで固定。通常パーツの色変更では変更されない。

このPCのレビュー用データは `.local/assembly-work/mini-parts/`。
単体2種類、No.1＋シャフト＋ホイール＋第3口のNo.2、No.2＋シャフト＋ホイール＋第3口のNo.1を別々の手順で見られる。
「確認する手順」で切り替え、「はなして見る」を左端へ動かすと結合位置を確認できる。
2026-09-14、実物写真に合わせたスポークの修正後、ユーザーが制作室用の表示モデルとして完成を承認。レビュー状態は確認済み。
写真からの推定寸法を採用しており、実測・実物での嵌合検証は未実施のまま記録している。

```sh
npm run assembly:review -- --workspace .local/assembly-work/mini-parts --port 5183
```

## Tailscaleから開く

このPCでは `https://mba1223.tail81f690.ts.net:5183/` から同じ制作室へアクセスできる。
再起動時はTailscaleのHTTPS originも指定する。制作室本体の待受はループバックのまま。

```sh
npm run assembly:review -- --workspace .local/assembly-work/mini-parts --port 5183 --external-origin https://mba1223.tail81f690.ts.net:5183
tailscale serve --bg --https=5183 5183
```

Tailscale ServeはこのPCの5183番で本制作室を転送する。別用途の既存Serve設定があれば上書き前に確認する。
停止は `tailscale serve --https=5183 off`。Macで制作室が起動し、利用端末がTailscaleに接続している必要がある。

| `img_popup_30@3x.png` | ミニホイールの黒タイヤ、白い3本スポーク、軸穴 |

板用の3口構成とNo.2への互換性はユーザー指定に基づく。初回の2口モデルを訂正した。
第3口は車軸と反対側へ向ける。旧データで `directions[2]` がない場合も、その方向を補完する。両方の板の共通辺17mm、全厚3.5mmは既存の採用値。
スペシャルパーツの大きさ・細部は画像からの推定値。公式寸法とは称さない。

| 表示モデルの採用値 | 値 |
| --- | --- |
| ホイール直径 / 幅 | 17 mm / 4.76 mm |
| 軸半径 / 軸穴半径 | 1.53 mm / 1.70 mm |
| シャフト中心からホイール中心 | 5.44 mm |

実物での嵌合、挿入経路、成形公差、裏側の細部は未確認。
タイヤ溝のU字末端と、白いスポークの浅い皿状の面は簡略化している。
ユーザーの実物確認を反映し、スポーク間は白い面で埋め、中央の軸穴だけを貫通させている。
追加の実物写真（私有の `photo-5`）に合わせ、3本のスポークを周囲の白い面より約1.3mm高くした。
外周の白リム・中央ハブより低い段差を保つ。高さは写真推定で、実測値ではない。
レビューで形状の差があれば、正面・裏面・側面と定規を添えた写真から補正する。
参照画像のコピーは私有 `.local/` のみで、公開アセットには含めない。

## データと検証範囲

- `partNo: "mini-shaft"` は `pose.center / axis / directions[0,1,2] / axleDirection`。
  `axis` は板の辺方向、`directions[0,1]` は対向する板の方向、`directions[2]` は車軸の反対方向、`axleDirection` は車軸方向。
- `partNo: "mini-wheel"` は `pose.center / axis`。`axis` は車軸方向。
- 板との接続は既存の `model.connections`（`port: 0/1/2`）。ホイールとは
  `model.axleConnections: [{shaft, wheel}]` と `actions: [{kind:"axle", shaft, wheel}]` を使う。
  軸接続を一般の板の差し込み口へ変換しない。
- 検証は参照、軸・穴の一対一占有、姿勢ベクトル、接続手順の網羅を確認する。
  追加・再接続操作は位置を合わせる。自由移動後の接合距離や全パーツの干渉は自動判定しない。
- 形状テストは貫通穴・フォークの空隙・割りピン、編集テストはNo.1/2接合と軸位置・削除・回転を確認する。
  ブラウザテストは追加→保存→再読込、移動したモデルの描画位置、接続矢印、単体表示を確認する。
- `special-parts.js` のメッシュは複数材質。ビューアーは上位Groupで分解表示の移動を受け、
  内側Groupの保存姿勢を保持する（保存位置を原点へ戻さない）。
