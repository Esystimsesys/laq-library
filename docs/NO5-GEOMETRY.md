# No.5の形状と接続位置

2026-09-12のユーザー提供写真（No.5単体3枚、No.1を2枚接続した写真3枚）を根拠にする。
ユーザーの実測は台形の短辺 **4 mm**。既に確認済みのNo.1の厚さは3.5 mm、辺は17 mm。
写真では、接続後の内面・外面ともNo.1からNo.5の爪まで高さがそろい、台形の側辺とNo.1の端面が接する。

`public/assemblies/viewer/realistic-parts.js` は120°の接続面から台形を構成する。
短辺4 mmと板厚3.5 mmから長辺7.5 mm、台形の高さ約3.0311 mmが得られる。
これらの長辺・高さは計算値であり、追加の実測値ではない。
板の中心面が交わる軸から接続辺の中点までの距離は
`(4 + 3.5 × cos(60°)) / (2 × sin(60°)) = 3.319764... mm`。
`LaQRealisticParts.obtuseJointInset()` はこれを17 mmで割った座標値を返す。
端のくぼみは台形の中央にあり、この仮想軸の上ではない。

爪の輪郭はNo.1/No.2共通のソケット曲線を用い、表裏の外面は板と同じ±1.75 mm。
以前の独立した台形寸法、円弧の爪、先端を0.25 mm薄くする処理は、接続時の段差・隙間の原因だった。
面の一致と輪郭の境目は `scripts/realistic-parts.test.mjs` で両面を検証する。
端面、差し込み溝、くぼみは `e2e/assembly-interactions.spec.ts` でも確認する。

## 既存作品の配置

旧No.5の接続距離は0.1（1.7 mm）の推定値だった。形状ファイルだけを更新しても、
作品の`pose`は新距離へ移動しない。姿勢・接続関係を保ち、No.5を介した塊の位置を調整する必要がある。
他のジョイントへ誤差を分配して見かけ上閉じる補正は行わない。

ジャローダ製作室では整合していた8個のNo.5を新距離へ調整済み。
`geometry.no5Calibration` に適用対象と保留対象を記録する。
`b1-j18`と`b1-j21`は修正前から接続先と約20 mmずれていたため保留し、既存の手動配置を保持した。
保存前のガイドは製作室の`history/`に残る。これは作品全体の組み立て可否の確認ではない。
