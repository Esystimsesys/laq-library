## このリポジトリは何か

LaQ公式「つくり方ギャラリー」の作品 245 件を、**さがす / おきにいり / つくった** の 3 目的で
引けるようにした、子ども向けスマホ PWA です。React 19 + TypeScript + Vite 8 + react-router v8、
CSS Modules、状態は localStorage のみ、サーバなし。Node 24（`.tool-versions`）。

作品の写真・つくり方の図・PDF は**ヨシリツ株式会社の著作物**で、このアプリは複製せず
`https://www.laq.co.jp/...` の URL を参照して表示するだけです。

## 絶対に守ること

1. **git commit / push はしない。** 変更が終わったら内容を報告して止まること。
   コミットするかどうかは人間が判断します。
2. **画像・PDF をリポジトリにダウンロードしない。** `src/data/data.test.ts` に
   「全URLが `https://www.laq.co.jp/` を指すこと」というテストがあり、これは意図的な歯止めです。
   オフライン対応のためにローカル同梱したくなっても、絶対にやらないこと。
3. **`src/data/sources/laq-official.json` を手で編集しない。**
   これは `npm run fetch:gallery`（= `scripts/fetch-gallery.mjs`）の生成物です。
   カテゴリを直したいときは `scripts/tag-rules.mjs` の辞書を直してから再生成します。
   `scripts/tag-rules.test.mjs` に「JSON と現在の辞書の出力が一致すること」を確かめる
   テストがあるので、片方だけ直すと落ちます。
4. **依存パッケージを気軽に足さない。** 日本語検索の正規化も自作しています（`src/lib/search.ts`）。
   足す必要があると思ったら、理由を添えて報告し、判断を人間に渡すこと。
5. **公式サイトへのアクセスは穏当に。** 取り込みスクリプトは直列 + 300ms 間隔 + HTMLキャッシュに
   なっています。この作法を崩さないこと。anti-bot 対策の解析・迂回はしません。

## コードの書き方

- **コメントは日本語で、「何をしているか」ではなく「なぜそうしたか」を書く。** 既存コードが
  すべてその方針なので、周りに合わせてください。自明な処理にコメントは付けません。
- UI の文言は**ひらがな中心**（未就学〜小学生が読む前提）。「さがす」「おきにいり」「つくった」
  「せってい」など、既存の言い回しに合わせること。
- デザインは「紙のずかんにカラフルなパーツのシールを貼った」方向です。
  **グラデーション背景・ぼかした影・ガラス風の半透明・絵文字を主役にしたUIは使わない。**
  輪郭線 + ずらしたハード影（`--shadow`）、丸ゴシック、`src/styles/tokens.css` の色で作ります。
- 操作できる要素は **44×44px 以上**。色は WCAG AA（通常文字 4.5:1）を満たすこと。
  `tokens.css` の色はその条件を満たすところまで濃くしてあるので、勝手に明るくしないこと。
