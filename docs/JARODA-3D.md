## 資料と再生成

私有の作業場所は `.local/assembly-work/jaroda/`。記事本文・元写真20枚・通常姿勢の完成写真1枚、
写真の方向と出典URL、観測と推測、候補生成器、検証結果を保存した。
写真と詳細な制作メモは公開データに含めない。

- `manifest.json` / `photos/` / `source-post.json` / `article.html`: 元資料。写真のSHA-256は `checks/source-checksums.json`。
- `HEAD-NECK-RECONSTRUCTION.md` / `BODY-TAIL-RECONSTRUCTION.md` / `review.json`: 写真観測と採用した推測。
- `generator/build_jaroda.py`: 頭・首と胴・尾の生成器を統合。既存のデスカーンの `laq_build.Model`、プロトタイプの部品カタログ・検査器を再利用。
- `generator/shared/`: 再利用コードとカタログの同一コピー。元ファイルのパスとSHA-256を `generator/DEPENDENCIES.json` に記録し、このプロジェクト内だけで再生成できる。
- `generator/check_model.py`: 保存済みガイドを読み直して、形状・接続・連結と板面交差を再検査。
- `import-candidate.mjs`: 現在のガイドを `--use-source-reading` 相当で取り込む。共通ビューアーを上書きしない。
- `checks/import-record.json` / `checks/final-import/`: 完成版の取り込み元・取り込み後のSHA-256と確認記録。

```sh
python3 .local/assembly-work/jaroda/generator/build_jaroda.py
python3 .local/assembly-work/jaroda/generator/check_model.py
node scripts/author-assembly.mjs validate --workspace .local/assembly-work/jaroda
npm run assembly:review -- --workspace .local/assembly-work/jaroda --port 5184
```

人が修正を始めた後は、再生成で上書きせず `guide.json` とレビューコメントを先に確認する。
旧v1〜v3は板の重複・省略、奥行きと三角の曲がり、完成姿勢に問題があるため不採用。
作業ガイドから除去し、調査用記録だけ `rejected/pre-rebuild/` に退避した。

## 確認したことと残る推測

写真の各方向を同じ塊として照合した。頭の黄緑と白、オレンジの目、平面U字の冠、黄色い襟、
胴体の縦壁・水平棚・黄緑の下面、曲がった胴体、C字の尾を再構成した。
座標の単位は辺長1=17mm、表示の厚さは3.5mm。既存の採用値であり、公式寸法とはしない。

頭の目周辺と冠の取り付け、首の白い側面、胴の隠れた面数、曲がった胴の板順、
尾の立ち上がりをNo.7の空き口とした点は推定。観測として確定したことと区別して `review.json` に残した。
元作品との完全一致や、実物の嵌合・板厚の干渉・挿入経路・強度を証明した図ではない。

初回取り込み時は、AIによる構造推定からローカル取り込みまでの依頼に従い、AI検証の候補として取り込んだ。
人の確認を必要とする `author-assembly export` は実行せず、`review.status` は `draft`、確認者・日時・hashは空欄のまま。
当時は人の確認済み・実物確認済みとは記録していない。完成版は冒頭のとおり人の確認後にexportして取り込んだ。実物未確認は維持する。
commit・push・本番公開は行っていない。
